# repair-master

Сайт-визитка для мастера по ремонту квартир.

## Что использовал
- HTML: семантическая верстка (`header`, `main`, `section`, `form`, `table`)
- CSS: Flexbox для построения сетки сайта (шапка, две колонки, галерея)
- CSS: стилизация форм, таблиц, карточек и кнопок
- CSS: эффекты при наведении (`:hover`)

## Особенности проекта
- Адаптивная шапка с закреплением при скролле (`sticky`)
- Форма обратной связи с валидацией полей
- Прайс-лист в виде аккуратной таблицы
- Галерея выполненных работ
